# Digital-Marketing-Performance-Dashboard
This is my first portfolio project using Power Bi.

## Project Overview
The dashboard shows the performance of a digital marketing company and the campaigns, ads and user engagement between May 7, 2005 to August 6, 2025. 

## Objective
- Evaluate the effectiveness of advertising campaigns 
- Analyzing user engagement and performance trends
- Identifying high-performing campaigns and advertisements
- Understanding audience behavior
- Measuring engagement, cost and user related KPIs 
- Providing insights that help optimize future marketing strategies and advertising spend

## Issues and Solutions
### Core Issues
- Purchases Have Collapsed
- Capital Efficiency is Broken (High CPC, CPP and CPM - 1000 impressions)
- Severe Funnel Leakage (Conversion Rate - 0.6%)
- Only about a quarter of purchases came from users matching the ad's intended target gender. 

### Suggestive Solutions 
- Reallocate Budget by Platform and Ad Type 
- Pause high-spend, low-yield campaigns and reallocate capital into high-converting outlier campaigns to improve AOI.
- Audit page load speeds, checkout flow friction, pricing alignment, or technical tracking errors
- Campaigns are working best in a small number of geographies — an opportunity to either double

## What I learned
- There is more to data preparation than data validation, alignment and formatting
- Learnt how numbers speak and which numbers matter when it comes to business decisions and reporting.

## Key Components 
- Used bookmark in Campaign analysis page to show a matrix which is displayed when we click on the image link 'All' (All Campaigns)
- AI Narrative implemented in Top Campaigns with a combo chart
- In Ad Analysis I have again used bookmark to use another AI tool - Key Influencer
